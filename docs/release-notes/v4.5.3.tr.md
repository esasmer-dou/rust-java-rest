# Rust-Java REST 4.5.3

`4.5.3`, sınırlı telemetri için kararlı bir request-path ve exporter scheduling iyileştirmesidir.
Mevcut Java handler, annotation, service, DTO, validation ve business logic kullanımı değişmez.

## Neler Değişti?

- Telemetri açıkken request capture durumu tek bir 32-bit alanda tutulur. Native request guard
  boyutu 32 byte'tan en fazla 24 byte'a düşer.
- HTTP sampling, ikinin kuvveti olarak ayarlanan her tam pencereden yine tam bir request seçer.
  Seçilen konum daha az hot-path işlemiyle döner. Periyodik route'lar kapsam dışında kalmaz.
- Tam 5xx sayımı ve isteğe bağlı sınırlı yavaş çağrı trace'leri değişmez.
- İzole exporter Hyper executor'ını kullanmaz. Linux'ta `SCHED_BATCH` ve `19` nice değeriyle,
  Windows'ta `THREAD_PRIORITY_LOWEST` ile çalışır.

## Uyumluluk

REST ABI `29`, Glowroot ABI `3`, Dubbo ABI `7` ve Redis ABI `6` olarak kalır.
`com.reactor:rust-java-rest:4.5.3` içinde paketlenen Windows DLL veya Linux SO dosyasını kullanın.
Startup kaynak revision ve SHA-256 doğrulaması yaptığı için native dosyayı farklı bir Maven sürümüne
kopyalamayın.
