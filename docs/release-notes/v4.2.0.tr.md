# Rust-Java REST 4.2.0

`4.2.0`, deklaratif framework deneyimini genişletir. Mimari sınır değişmez: Rust Hyper HTTP I/O ve
bounded native transport işlerini yürütür. Handler, service, validation, SQL ve business kararları
Java'da kalır.

## Servis Başlatma

```xml
<parent>
  <groupId>com.reactor</groupId>
  <artifactId>rust-java-platform-parent</artifactId>
  <version>4.2.0</version>
  <relativePath/>
</parent>

<dependencies>
  <dependency>
    <groupId>com.reactor</groupId>
    <artifactId>rust-java-starter-rest</artifactId>
  </dependency>
</dependencies>
```

```java
@ReactorApplication(scanBasePackages = "com.example.orders")
public final class OrderApplication {
    public static void main(String[] args) {
        Reactor.run(OrderApplication.class, args);
    }
}
```

Platform parent, uyumlu dependency ve codegen sürümlerini yönetir. Servise yalnız ihtiyacı olan
starter'ı ekleyin. Cache, Dubbo, WebSocket, tracing, scheduler, security ve OpenAPI varsayılan
runtime yüzeyine eklenmez.

## Neler Eklendi?

- REST, WebSocket, OpenAPI, security, tracing, scheduler, HTTP client, Dubbo, cache reader/writer ve
  test için ayrı starter'lar.
- Build-time generated DI, route invocation, primitive binding, configuration binding, validation,
  exception handling ve application descriptor yapıları.
- Açık status, header ve typed error yönetimi için `HttpResponse<T>` ve `ProblemDetail`.
- Request-time reflection eklemeden generated HTTP client ve application feature extension point'leri.
- Startup sonrasında immutable native route lookup.
- Classpath scanning'e bilinçli olarak ihtiyaç duyan uygulamalar için ayrı compatibility modülü.
- Her service shape için en küçük dependency setini ve çift dilli README'yi üreten project generator.

## Güncelleme Adımları

1. Platform parent veya doğrudan REST dependency sürümünü `4.2.0` yapın.
2. Aynı process içindeki native Dubbo/cache library'lerini `0.7.0` yapın.
3. Platform parent kullanıyorsanız elle yazılmış annotation processor path'lerini kaldırın.
4. Yalnız gerekli starter'ları seçin. Tüm starter'ları peşinen eklemeyin.
5. Bu sürümle paketlenen DLL/SO'yu kullanın. REST ABI `24` binary startup sırasında reddedilir.

Java business API'si Rust'a taşınmadı. Mevcut handler annotation'ları ve service sınıfları geçerlidir.
İzole veya ileri runtime yüzeylerinde `RestApplication.Module` kullanılmaya devam edilebilir.
