# rust-java-rest v3.2.7

`v3.2.7` keeps the native runtime ABI line unchanged and adds a cleaner configuration workflow for
sample and production applications.

## What's New

- Added `reactor.config.file` / `REACTOR_CONFIG_FILE` overlay support.
- Applications can keep a small classpath `rust-spring.properties` and apply one or more external
  production or advanced tuning files.
- Overlay keys are treated as explicit runtime configuration, so runtime profiles do not overwrite
  them.

## How To Use

```powershell
java "-Dreactor.config.file=config/production.properties" -jar app.jar
```

Multiple overlays are loaded in order:

```powershell
java "-Dreactor.config.file=config/production.properties;config/advanced-tuning.properties" -jar app.jar
```

## Compatibility

- Native ABI did not change.
- Java REST annotations and handler APIs did not change.
- Existing applications with a single `rust-spring.properties` continue to work.
