# Rust-Java REST 4.5.0

`4.5.0`, mevcut Java REST programlama modelini değiştirmeden çalışma sırasında değiştirilebilen
sınırlı Glowroot telemetri profillerini ekler.

## Kullanıcı Ne Kazanır?

- En küçük telemetri yüzeyi için `reactor.glowroot.profile=micro` ile başlayabilirsiniz.
- Olay incelemesi sırasında geçici olarak `jvm`, `sql`, `full` veya `diagnostic` profiline
  geçebilirsiniz.
- `GlowrootTelemetry.restoreConfiguredProfile()` ile başlangıç profiline dönebilirsiniz. Profile ait
  native memory ve JNI referansları senkron biçimde bırakılır.
- Bytecode weaving, Java gRPC veya Netty eklemeden JVM memory/GC ölçümleri, açık SQL işlem süreleri,
  sınırlı hata stack'leri ve yetkilendirilmiş thread/heap tanılaması alabilirsiniz.
- Telemetri işi, `256 KiB` stack kullanan ayrı bir Rust thread'inde çalışır. Hyper ve application
  worker'ları kullanılmaz.

## En Küçük Ayar Seti

```properties
reactor.glowroot.enabled=true
reactor.glowroot.profile=micro
reactor.glowroot.collector.address=http://glowroot-collector:8181
reactor.glowroot.agent.id=catalog::pod-1
reactor.glowroot.application.name=catalog-api
```

```java
GlowrootTelemetry.switchTo(TelemetryProfile.FULL, Duration.ofSeconds(5));
try {
    // Sınırlı olay incelemesini çalıştırın.
} finally {
    GlowrootTelemetry.restoreConfiguredProfile();
}
```

Profil değiştirme veya diagnostic komutlarını kimlik doğrulaması olmayan public endpoint üzerinden
açmayın.

## Native Uyumluluk

| Kontrat | Değer |
| --- | ---: |
| REST ABI | `29` |
| Dubbo ABI | `7` |
| Redis ABI | `6` |
| Glowroot ABI | `3` |

Paketlenen Windows DLL ve Linux SO aynı temiz `rust-spring v4.5.0` commit'inden üretilir. SHA-256
değerleri ve 40 karakterli kaynak revision Maven provenance manifestine yazılır. REST `4.4.x` veya
agent `0.2.x` sürümündeki DLL/SO dosyasını kopyalamayın.

Java annotation, handler, service, validation, record, database erişimi, RPC çağrısı ve business
logic kullanımı `4.4.1` ile source-compatible kalır.
