# Rust-Java REST 4.4.0

`4.4.0`, mevcut Glowroot Central kurulumuna veri gönderebilen isteğe bağlı Rust telemetry katmanını
ekler. Java handler, service, record, validation ve iş mantığı aynı şekilde çalışmaya devam eder.

## Uyumlu Sürümler

| Artifact | Sürüm | Görevi |
| --- | ---: | --- |
| `com.reactor:rust-java-rest` | `4.4.0` | REST runtime ve native HTTP transport |
| `com.reactor:java-rust-cache` | `0.7.2` | Native Redis entegrasyonu |
| `com.reactor:java-rust-dubbo` | `0.7.2` | Native Dubbo consumer entegrasyonu |
| `com.reactor:java-rust-glowroot-agent` | `0.2.0` | İsteğe bağlı `-javaagent` başlangıç katmanı |
| `com.reactor:java-rust-glowroot-spring-boot-starter` | `0.2.0` | Ayrı Spring Boot adaptörü |

## Nasıl Kullanılır?

- Telemetry gerekmiyorsa kapalı bırakın. Bu durumda route tablosu, kuyruk ve collector bağlantısı
  oluşturulmaz.
- HTTP route özetleri, native Dubbo/Redis süreleri, process RSS, thread sayısı ve exporter sağlığı
  için sınırlandırılmış `micro` profilini açın.
- Lokal durumu `/diagnostics/glowroot` ve `reactor_glowroot_*` Prometheus metriklerinden okuyun.
- Mevcut Glowroot Central deployment'ını kullanmaya devam edin. Collector plugin'i gerekmez.
- Spring Boot uygulamasında ayrı Spring Boot starter'ını kullanın. Spring bağımlılıkları Rust-Java
  REST artifact'ine eklenmez.

```properties
reactor.glowroot.enabled=true
reactor.glowroot.profile=micro
reactor.glowroot.collector.address=http://glowroot-central:8181
reactor.glowroot.agent.id=${HOSTNAME}
reactor.glowroot.application.name=order-api
reactor.glowroot.http.sample-rate=256
reactor.glowroot.trace.capacity=0
```

## Native Güvenlik

REST ABI `26` değerinden `28` değerine yükselir. Dubbo ABI `7`, Redis ABI `6` olarak kalır. Glowroot
ABI `1` değeridir. Startup; tüm ABI değerlerini, platformu, Rust kaynak commit'ini ve paketlenmiş
SHA-256 değerini trafik başlamadan doğrular.

Paket içindeki Windows ve Linux dosyaları temiz CI ortamında
`28688c3fca2618d469267ea4e61481a4295387f1` Rust commit'inden üretildi. Eski sürümden DLL/SO
kopyalamayın.

## Kapsam

Mikro ajan herhangi bir Java metodunu weave etmez. JDBC SQL metni, JMX discovery, profiler ve log
capture özelliklerini içermez. Bu özellikler gerekiyorsa tam Glowroot Java agent'ını kullanın.
Sınırlandırılmış mikro yol, düşük maliyetli HTTP/RPC/cache telemetry içindir.
