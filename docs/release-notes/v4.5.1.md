# Rust-Java REST 4.5.1

`4.5.1` is a stable native performance-isolation patch. Java annotations, handlers, services,
validation, records, and business logic remain unchanged.

## What Users Get

- The bounded Glowroot collector connection is prepared before the first aggregate boundary. A
  one-vCPU service no longer performs its initial DNS/TCP/HTTP2/init work in the middle of the first
  telemetry interval.
- The isolated Rust exporter runs at a lower operating-system scheduling priority. HTTP traffic
  remains the priority when telemetry is exported under CPU pressure.
- Telemetry sampling, weighting, memory limits, profiles, and fail-open behavior are unchanged.
- Telemetry remains disabled by default. A disabled application creates no exporter thread or
  collector connection.

## Compatibility

| Contract | Value |
| --- | ---: |
| REST ABI | `29` |
| Dubbo ABI | `7` |
| Redis ABI | `6` |
| Glowroot ABI | `3` |

Use the Windows DLL and Linux SO packaged in `com.reactor:rust-java-rest:4.5.1`. Both artifacts were
built from the same clean `rust-spring` commit and are verified by the packaged provenance manifest.
Do not copy a native file from another release.
