# 4.9.0: Dosya Yükleme, WebSocket ve Paketli Dosyalar

[English](v4.9.0.md) | [Turkish](v4.9.0.tr.md)

## Güncelleme

`com.reactor:rust-java-rest` ve REST platform parent/BOM sürümünü `4.9.0` yapın.
Bu paketteki native dosyayı kullanın. DLL, SO veya dylib yolunu
`-Drust.lib.path` ile veriyorsanız o dosyayı da değiştirin. Varsayılan köprü
JNI'dır. REST 29, Dubbo 7, Spring Dubbo 3, Redis 6 ve Glowroot 6 değişmedi.

## Hangi Yolu Seçmeliyim?

| İhtiyaç | Yapmanız gereken |
| --- | --- |
| Formdan dosya alıp `MultipartFile` olarak işlemek | Mevcut metodunuzu koruyun. Bölüm sınırlarını Rust bulur. Dosya limitleri değişmez. Bu işlem akış tabanlı yükleme değildir. |
| İkili WebSocket mesajını olduğu gibi geri göndermek veya düşürmek | Uç noktada `WebSocketBinaryForwarder` uygulayın. Gelen baytları aynı bağlantıya göndermek için `true` döndürün. |
| İkili mesajı incelemek, dönüştürmek veya başka bağlantılara göndermek | `byte[]` alan `@OnMessage` metodunu koruyun. Yeni yol metin ve yaşam döngüsü metotlarını değiştirmez. |
| JAR içinden herkese açık sabit dosya sunmak | Dosyayı derlemede hazırlayın. Tam bir GET rotasında `@NativeStaticFileRoute` kullanın. Rust uygun gzip veya sıkıştırılmamış sürümü, kendi ETag değeriyle sunar. |
| Yetki denetimli, dinamik veya parçalı dosya sunmak | Mevcut yanıt veya dosya yolunu kullanın. Paketli dosyalar Java istek işlemesinden geçmez ve byte range desteklemez. |

## WebSocket Örneği

```java
import com.reactor.rust.websocket.WebSocketBinaryForwarder;
import com.reactor.rust.websocket.WebSocketSession;
import com.reactor.rust.websocket.annotation.WebSocket;

@WebSocket("/ws/echo")
public final class BinaryEcho implements WebSocketBinaryForwarder {
    public boolean shouldForwardBinary(WebSocketSession session, int length) {
        return length <= 64 * 1024;
    }
}
```

Uç noktayı bean olarak kaydedin. `reactor.websocket.enabled=true` ile WebSocket'i
açın. Karar veren metotta ağ veya veritabanı çağrısı yapmayın.

## Paketli Dosya Örneği

JAR'ı oluşturmadan önce, REST bağımlılığı Java classpath'indeyken şu komutu
çalıştırın:

```text
java -cp <classpath> com.reactor.rust.http.PackagedAsset target/classes/assets/app.js application/javascript
```

Asıl dosyayı ve hazırlanan yan dosyaları birlikte paketleyin.

```java
@GetMapping(value = "/assets/app.js", responseType = FileResponse.class)
@NativeStaticFileRoute
public FileResponse script() {
    return FileResponse.packagedAsset(getClass(), "/assets/app.js")
            .header("Cache-Control", "public, max-age=600");
}
```

Bu sürüm yalnız bu kullanım yollarını kapsar. Tüm RD deneylerinin performans
kabulünü geçtiği veya her iş yükünün hızlandığı anlamına gelmez.
