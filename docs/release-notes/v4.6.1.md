# Rust-Java REST 4.6.1

[English](v4.6.1.md) | [Turkish](v4.6.1.tr.md)

`4.6.1` completes bounded Spring trace detail and the live JVM connection expected by Glowroot
Central. Java handlers, annotations, services, records, validation, and business logic are
unchanged.

## What Users Get

- **Useful slow/error traces.** Diagnostic traces can show HTTP method, response status, Spring
  controller entry and timing, request-thread CPU/blocked/waited/allocation counters, nested Dubbo
  timing, and a bounded exception stack.
- **Live JVM operations.** Thread dump, OpenJ9 heap histogram/dump, Force GC, MBean tree, System
  Properties, and capability requests use a separate bidirectional collector connection.
- **Safer environment data.** Host, process, Java/OpenJ9, masked JVM arguments, dump directory, and
  agent version are reported. Arbitrary OS environment variables are not exported because they can
  contain Kubernetes secrets.
- **No request-path exporter work.** Export and live diagnostics stay on the isolated Rust runtime,
  not on Hyper or Java application workers.
- **No payload retention.** Request/response bodies and Dubbo arguments/results are not captured.

## Maven

```xml
<dependency>
  <groupId>com.reactor</groupId>
  <artifactId>rust-java-rest</artifactId>
  <version>4.6.1</version>
</dependency>
```

Use the DLL/SO packaged by this dependency. The release uses REST ABI `29` and Glowroot ABI `6`.
An older native file is intentionally rejected during startup. Spring Boot applications use the
coordinated `java-rust-glowroot-spring-boot-starter:0.5.2` package and its standalone native file.

## Diagnostic Verification

1. Set `REACTOR_GLOWROOT_ENABLED=true` and `REACTOR_GLOWROOT_PROFILE=diagnostic`.
2. Send successful, slow, and failing requests through a Spring controller.
3. Confirm the startup log contains `Java-Rust Glowroot live diagnostics connected`.
4. In Glowroot, inspect **Transactions > Web** and open a slow/error trace.
5. Verify **Thread dump**, **Heap histogram**, **MBean tree**, and **System properties** while the pod
   is connected.

Windows and Linux native files are built from clean `rust-spring v4.6.1` source revision
`121888cbfe8cd28a32fd4489685f58c6e30642cb`. The Linux artifact is limited to GLIBC `2.17` symbols.
