# Rust-Java REST 4.6.1

[English](v4.6.1.md) | [Türkçe](v4.6.1.tr.md)

`4.6.1`, sınırlı Spring trace ayrıntısını ve Glowroot Central'ın beklediği canlı JVM bağlantısını
tamamlar. Java handler, annotation, service, record, validation ve iş mantığı değişmez.

## Kullanıcıya Ne Sağlar?

- **Açıklayıcı yavaş/hatalı trace.** Diagnostic trace; HTTP metodu, response kodu, Spring controller
  satırı ve süresi, request thread CPU/blocked/waited/allocation sayaçları, iç Dubbo süresi ve
  sınırlı exception stack bilgisini gösterebilir.
- **Canlı JVM işlemleri.** Thread dump, OpenJ9 heap histogram/dump, Force GC, MBean tree, System
  Properties ve capability istekleri ayrı çift yönlü collector bağlantısını kullanır.
- **Güvenli ortam bilgisi.** Host, process, Java/OpenJ9, maskelenmiş JVM argümanları, dump dizini ve
  agent sürümü gönderilir. Kubernetes secret içerebildiği için bütün işletim sistemi environment
  variable değerleri gönderilmez.
- **Request yolunda exporter işi yoktur.** Export ve canlı tanılama Hyper veya Java application
  worker'ı yerine izole Rust runtime'ında çalışır.
- **Payload tutulmaz.** Request/response body ve Dubbo argüman/sonuç değerleri yakalanmaz.

## Maven

```xml
<dependency>
  <groupId>com.reactor</groupId>
  <artifactId>rust-java-rest</artifactId>
  <version>4.6.1</version>
</dependency>
```

Bu dependency ile gelen DLL/SO dosyasını kullanın. Sürüm REST ABI `29` ve Glowroot ABI `6` kullanır.
Eski native dosya startup sırasında bilinçli olarak reddedilir. Spring Boot uygulamaları uyumlu
`java-rust-glowroot-spring-boot-starter:0.5.2` paketini ve onun standalone native dosyasını kullanır.

## Diagnostic Doğrulaması

1. `REACTOR_GLOWROOT_ENABLED=true` ve `REACTOR_GLOWROOT_PROFILE=diagnostic` verin.
2. Spring controller üzerinden başarılı, yavaş ve hatalı istek gönderin.
3. Startup logunda `Java-Rust Glowroot live diagnostics connected` satırını doğrulayın.
4. Glowroot içinde **Transactions > Web** ekranından yavaş/hatalı trace açın.
5. Pod bağlıyken **Thread dump**, **Heap histogram**, **MBean tree** ve **System properties**
   ekranlarını doğrulayın.

Windows ve Linux native dosyaları temiz `rust-spring v4.6.1` kaynak revision
`121888cbfe8cd28a32fd4489685f58c6e30642cb` üzerinden üretilir. Linux dosyası GLIBC `2.17` sembol
sınırını korur.
