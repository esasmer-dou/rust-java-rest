# Rust-Java REST 4.5.2

`4.5.2` stable bir telemetri scheduling düzeltmesidir. Mevcut Java handler, annotation, service,
DTO, validation ve business logic kullanımı değişmez.

## Neler Değişti?

- Embedded REST telemetrisi başlangıçta collector erişimini doğrular ve bu bağlantıyı kapatır.
- Sınırlı h2 bağlantısını yalnız export penceresinde açar. Idle collector bağlantısı, Hyper request
  akışının CPU bütçesini paylaşmaz.
- Standalone Spring agent, izole Rust runtime içinde tek sınırlı collector bağlantısını yeniden
  kullanmaya devam eder.
- Exporter düşük öncelikli tek `256 KiB` native thread üzerinde kalır.

## Uyumluluk

REST ABI `29`, Glowroot ABI `3`, Dubbo ABI `7` ve Redis ABI `6` olarak kalır.
`com.reactor:rust-java-rest:4.5.2` içinde paketlenen Windows DLL veya Linux SO dosyasını kullanın.
Startup kaynak revision ve SHA-256 doğrulaması yaptığı için native dosyayı farklı bir Maven sürümüne
kopyalamayın.
