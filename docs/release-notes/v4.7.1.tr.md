# Rust-Java REST 4.7.1

Platform kaynak tag'i `platform-v4.7.1`, core kaynak tag'i `v4.7.1` olur. Mevcut core tag'i değişmedi.
Platform ilk yayımlanmadan önce iki cache starter'ı da cache `0.8.1` ile eşlendi.
Maven sürümü `4.7.1` olarak kalır. Platform paketi kendi kaynak commit bilgisini içerir.

[English](v4.7.1.md) | [Türkçe](v4.7.1.tr.md)

## Uygulamanızda Ne Değişir?

Java handler, service ve annotation kullanımı değişmez. Platform parent/BOM ve REST bağımlılıklarını birlikte `4.7.1` yapın. Bu paketin native dosyalarını kullanın. Eski DLL veya SO kopyalamayın.

Telemetri kapalıysa exporter başlamaz. Micro telemetri açık ve trace kapasitesi sıfırsa her isteğin sayısı, hatası ve süresi yine eksiksiz toplanır. Kullanılmayan trace seçimi artık yapılmaz. Tamamlanma yolu nanosaniye değerlerini doğrudan Rust sayaçlarına iletir. Sınırlı trace kuyruğu açıldığında diagnostic ayrıntıları korunur.

Heap, worker, bağlantı veya kuyruk limitleri büyütülmez. Yeni JVM ayarı gerekmez. Export, Hyper istek executor'ında değil, ayrı Rust exporter'ında çalışır. HTTP yanıtları önbelleğe alınmaz.

## Native Uyumluluk

Temiz kaynak: `ccf11143cea8b7513706c439c67939b7803469d0`. REST ABI `29`, Dubbo `7`, Redis `6`, Glowroot `6` değişmez. Windows x64, Linux x64/ARM64 ve macOS ARM64 birlikte paketlenir. Linux GLIBC alt sınırı `2.17` olarak kalır.

Exporter henüz çalışmadan iptal edilirse native sahiplik artık bırakılır. Hızlı kapanış ve yeniden
başlangıçta eski sahiplik bayrağı takılı kalmaz. Cache starter, `java-rust-cache:0.8.1` ile hizalanır.
REST olmadan çalışan cache uygulaması da düzeltilmiş motoru alır. Redis API ve varsayılanları değişmez.

## Yayın Kontrolü

Eşleşen agent 0.7.0 [performans kontrolü](https://github.com/esasmer-dou/java-rust-glowroot-agent/actions/runs/39381789571) yayından önce geçti. Micro açık/kapalı olarak küçük ve hazır JSON, c64/c256 ve en az üç geçerli eş koşu ölçüldü. Eş koşullu medyanda RSS/container farkı en fazla 3 MiB olabilir. Başarılı RPS kaybı en fazla %2, p99 artışı en fazla %10 olabilir. Hata, başlangıç ve thread kontrolleri de korunur. Bu ölçüm, her RSS tepesinin 3 MiB altında kalacağı anlamına gelmez.
