# Rust-Java REST 4.5.6

[English](v4.5.6.md) | [Türkçe](v4.5.6.tr.md)

`4.5.6`, platform parent ve starter kullanan uygulamalar için dependency hizalama patch'idir. Java
handler, annotation, service, record, validation ve iş mantığı değişmedi.

## Kullanıcıya Gelen Değişiklikler

- `rust-java-platform-parent`, BOM, starter, örnek, proje üretici ve build gate sürümleri `4.5.6`
  olarak hizalandı.
- Uyumlu ek kütüphane hattı `java-rust-cache:0.7.5`, `java-rust-dubbo:0.7.3`,
  `rust-sample-model:0.4.2` ve `rest-sample-utility:0.4.2` oldu.
- Windows ve Linux native dosyaları temiz `rust-spring v4.5.5` revision'ı
  `0498f282556d3f0778a92956b18eaaf96d5c0916` üzerinden gelir. SHA-256 değerleri REST `4.5.5` ile
  aynıdır.
- REST ABI `29`, Dubbo ABI `7`, Redis ABI `6` ve Glowroot ABI `3` değişmedi.

## Önerilen Kurulum

```xml
<parent>
  <groupId>com.reactor</groupId>
  <artifactId>rust-java-platform-parent</artifactId>
  <version>4.5.6</version>
  <relativePath/>
</parent>
```

Yalnız process'in ihtiyaç duyduğu starter'ları seçin. Parent, codegen paketlerini derleyici yolunda
tutar. Kullanılmayan Dubbo, Redis, scheduler veya WebSocket runtime yüzeyini eklemez.

`rust-java-rest:4.5.6` içinde gelen DLL/SO dosyasını kullanın. Farklı ABI veya provenance hattından
native dosya kopyalamayın.
