# Rust-Java REST 4.3.0

`4.3.0`; startup, generated route çalıştırma ve resident memory alanlarını iyileştirir. Uygulama
kodunun yeri değişmez. Handler, service, record, validation, veri tabanı erişimi ve iş kuralları
Java'da kalır. Rust; HTTP I/O, sınırlı native buffer, response transport ve seçilmiş serialization
işlerini yönetmeye devam eder.

## Sürüm Yükseltme

Mümkünse uyumlu platform parent'ını kullanın:

```xml
<parent>
  <groupId>com.reactor</groupId>
  <artifactId>rust-java-platform-parent</artifactId>
  <version>4.3.0</version>
</parent>
```

Uyumlu sürüm çizgisi şöyledir:

| Artefact | Sürüm | Görevi |
| --- | ---: | --- |
| `rust-java-rest` | `4.3.0` | REST runtime, codegen ve native HTTP transport |
| `java-rust-dubbo` | `0.7.1` | Native Dubbo consumer entegrasyonu |
| `java-rust-cache` | `0.7.1` | Native Redis entegrasyonu |
| `rust-sample-model` | `0.4.1` | Ortak sample record'ları |
| `rest-sample-utility` | `0.4.1` | Ortak sample kontratları |

Her zaman bu sürümle gelen DLL/SO dosyasını kullanın. REST ABI `26` olarak kalır. Ancak native
uygulama ve dosya hash'leri değişmiştir.

## Kullanıcı İçin Neler Değişti?

### Normal response record'ları

Normal JSON DTO'larında `@Response` kullanmaya devam edin:

```java
@Response
record CatalogItem(long id, String name) {}
```

Bu kullanım desteklenen normal serializer yolunu seçer. Kendiliğinden direct writer üretmez.

### Yoğun çağrı alan response record'ları

Profil ölçümü bir JSON response'un yoğun olduğunu gösteriyorsa `@GenerateDirectJsonWriter`
ekleyin:

```java
@Response
@GenerateDirectJsonWriter
record CatalogItem(long id, String name) {}
```

Writer build sırasında üretilir ve trafik başlamadan bağlanır. Desteklenmeyen bir veri yapısı her
request'te sessizce yavaş yola düşmez; build aşamasında açık hata verir. Route diagnostics seçilen
yolu gösterir.

### Startup ve image hazırlığı

Generated component descriptor'ları, route invoker'ları ve native digest kontrolleri daha az geçici
durum tutar. Maven runtime-image yolu OpenJ9 shared class cache hazırlayabilir. Build araçları runtime
image'a girmez. Bu seçeneği servis bazında kullanın. Birlikte gelen startup ve resident-image
testleriyle doğrulayın.

## Performance Gate Sonucu

Release gate aynı uygulamanın değişiklik öncesi ve sonrası sürümlerini karşılaştırdı. Generated
invocation, c64/c256 testlerinde useful RPS değerini yaklaşık `%2,6-%3,0` artırdı. p99 yaklaşık
`%2,0-%4,1` azaldı. Echo ve small-direct no-regression sınırında kaldı. Framework iç ready süresi
yaklaşık `%3,3` iyileşti. Route ve concurrency değerine göre memory farkı yaklaşık `-0,47 MiB` ile
`+0,59 MiB` aralığında kaldı. Bu sayılar release gate sonucudur. Her iş yükü için sabit vaat değildir.

## Uyumluluk

- Mevcut Java handler ve service kodu geçerlidir.
- Mevcut `@Response` DTO'ları geçerlidir.
- Açıkça `@GenerateDirectJsonWriter` kullanan DTO'lar generated yolu kullanmaya devam eder.
- Native ABI numarası değişmedi.
- `4.2.0` native binary dosyalarını tekrar kullanmayın. Hash değerleri sürüme özeldir.
