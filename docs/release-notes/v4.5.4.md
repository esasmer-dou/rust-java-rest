# Rust-Java REST 4.5.4

`4.5.4` is a compatible native request-path optimization for applications that enable bounded
Glowroot telemetry. Java handlers, annotations, services, validation, DTOs, and business logic do
not change.

## What Changed

- Unsampled successful requests with slow tracing disabled now leave the Rust telemetry path through
  one compact fast-path check.
- The power-of-two HTTP sampling shift is precomputed at startup instead of being recalculated for
  every request.
- Exact bounded sampling frequency, periodic-route protection, exact `5xx` capture, and the isolated
  exporter remain intact.
- Windows and Linux native files come from clean `rust-spring v4.5.4` CI builds and carry exact
  source-revision and SHA-256 provenance.

## Compatibility

REST ABI `29`, Dubbo ABI `7`, Redis ABI `6`, and Glowroot ABI `3` are unchanged. Use the DLL/SO
packaged inside `com.reactor:rust-java-rest:4.5.4`; do not copy a native file from another release.
