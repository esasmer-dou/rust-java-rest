# Rust-Java REST 4.4.1

`4.4.1` is a stable production provenance patch. It does not change the Java programming model or
the HTTP hot path.

## What Changed

- The packaged Windows and Linux native libraries come from clean `rust-spring v4.4.2` CI builds.
- Native build information now reports the complete 40-character source commit SHA.
- The Maven provenance manifest contains the same exact source revision and verified SHA-256 hashes.
- A packaged-runtime regression test loads the real native library and validates the complete
  provenance contract before server startup.

## Compatibility

| Contract | Value |
| --- | ---: |
| REST ABI | `28` |
| Dubbo ABI | `7` |
| Redis ABI | `6` |
| Glowroot ABI | `1` |

Java annotations, handlers, services, records, validation, route behavior, and business logic are
unchanged. Use the DLL/SO carried inside `com.reactor:rust-java-rest:4.4.1`; do not copy a native
file from another release.
