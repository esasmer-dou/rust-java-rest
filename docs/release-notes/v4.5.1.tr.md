# Rust-Java REST 4.5.1

`4.5.1`, stable native performans izolasyonu düzeltmesidir. Java annotation, handler, service,
validation, record ve iş mantığı değişmez.

## Kullanıcı Ne Kazanır?

- Sınırlı Glowroot collector bağlantısı ilk aggregate zamanından önce hazırlanır. Tek vCPU kullanan
  servis, ilk DNS/TCP/HTTP2/init işlemini telemetry aralığının ortasında yapmaz.
- İzole Rust exporter daha düşük işletim sistemi önceliğiyle çalışır. CPU baskısı altında telemetry
  gönderilirken HTTP trafiği öncelikli kalır.
- Telemetry sampling, ağırlıklandırma, memory limitleri, profiller ve fail-open davranışı değişmez.
- Telemetry varsayılan olarak kapalıdır. Kapalı uygulama exporter thread'i veya collector bağlantısı
  oluşturmaz.

## Uyumluluk

| Sözleşme | Değer |
| --- | ---: |
| REST ABI | `29` |
| Dubbo ABI | `7` |
| Redis ABI | `6` |
| Glowroot ABI | `3` |

`com.reactor:rust-java-rest:4.5.1` içinde paketlenen Windows DLL ve Linux SO dosyalarını kullanın.
İki dosya aynı temiz `rust-spring` commit'inden üretilir ve paketteki provenance manifestiyle
doğrulanır. Başka bir sürümden native dosya kopyalamayın.
