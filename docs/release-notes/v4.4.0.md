# Rust-Java REST 4.4.0

`4.4.0` adds an optional Rust-first telemetry plane for teams that already use Glowroot Central.
Java handlers, services, records, validation, and business logic continue to work as before.

## Coordinated Versions

| Artifact | Version | Purpose |
| --- | ---: | --- |
| `com.reactor:rust-java-rest` | `4.4.0` | REST runtime and native HTTP transport |
| `com.reactor:java-rust-cache` | `0.7.2` | Native Redis integration |
| `com.reactor:java-rust-dubbo` | `0.7.2` | Native Dubbo consumer integration |
| `com.reactor:java-rust-glowroot-agent` | `0.2.0` | Optional `-javaagent` bootstrap |
| `com.reactor:java-rust-glowroot-spring-boot-starter` | `0.2.0` | Separate Spring Boot adapter |

## What You Can Use

- Keep telemetry off for zero telemetry state and no collector connection.
- Enable the bounded `micro` profile to export HTTP route aggregates, native Dubbo/Redis timings,
  process RSS, thread count, exporter health, and sampled slow/error traces.
- Read local state from `/diagnostics/glowroot` and `reactor_glowroot_*` Prometheus metrics.
- Keep the existing Glowroot Central deployment. No collector plugin is required.
- Use the separate Spring Boot starter when the monitored application is Spring Boot. Spring
  dependencies and the standalone agent binary do not enter the Rust-Java REST artifact.

```properties
reactor.glowroot.enabled=true
reactor.glowroot.profile=micro
reactor.glowroot.collector.address=http://glowroot-central:8181
reactor.glowroot.agent.id=${HOSTNAME}
reactor.glowroot.application.name=order-api
reactor.glowroot.http.sample-rate=256
reactor.glowroot.trace.capacity=0
```

## Native Safety

REST ABI advances from `26` to `28`. Dubbo ABI remains `7`, Redis ABI remains `6`, and Glowroot ABI
is `1`. Startup validates every ABI, the platform, the full Rust source revision, and the packaged
SHA-256 before serving traffic.

The packaged Windows and Linux binaries were produced by clean CI from Rust revision
`28688c3fca2618d469267ea4e61481a4295387f1`. Do not copy a DLL/SO from an older release.

## Scope

This micro agent intentionally does not provide arbitrary method weaving, JDBC SQL capture, JMX
discovery, profiling, or log capture. Use the full Glowroot Java agent when those features are
required. The bounded micro path is for low-overhead HTTP/RPC/cache telemetry.
