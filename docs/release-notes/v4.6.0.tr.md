# Rust-Java REST 4.6.0

[English](v4.6.0.md) | [Türkçe](v4.6.0.tr.md)

`4.6.0`, sınırlı HTTP telemetrisini mevcut Glowroot transaction ekranlarında görünür hale getirir.
Java handler veya REST annotation kullanımı değişmez.

## Kullanıcıya Ne Sağlar?

- **Average, Percentile, Throughput ve Errors tam istek sayısını kullanır.** Başarılı istekler trace
  örnekleme oranı nedeniyle dashboard verisinden çıkmaz.
- **Transaction verisi Glowroot'un beklediği biçimdedir.** Transaction type olarak `Web` seçin.
  `/orders/{id}` route'u `/orders/*` adıyla görünür.
- **Trace maliyeti sınırlı kalır.** `reactor.glowroot.http.sample-rate` yalnız isteğe bağlı trace
  ayrıntısını kontrol eder. Aggregate ekranları yeterliyse `reactor.glowroot.trace.capacity=0`
  değerini koruyun.
- **Endpoint çeşitliliği sınırlıdır.** Fazla route adları kaybolmaz;
  `<route-limit-exceeded>` altında görünür.

## Maven

```xml
<dependency>
  <groupId>com.reactor</groupId>
  <artifactId>rust-java-rest</artifactId>
  <version>4.6.0</version>
</dependency>
```

Bu dependency ile gelen DLL/SO dosyasını kullanın. Sürüm REST ABI `29` ve Glowroot ABI `4` taşır.
ABI `3` native dosyası startup sırasında bilinçli olarak reddedilir.

Aynı uygulama cache kütüphanesini de kullanıyorsa `java-rust-cache:0.7.6` seçin. Platform BOM ve
cache starter'ları bu koordineli paketi otomatik olarak kullanır. Paket aynı ABI `4` native
revision'ını taşır.

## Doğrulama

1. Uygulamayı sınırlı Glowroot telemetrisi açık olarak başlatın.
2. En az iki eşleşen route'a istek gönderin.
3. Bir export aralığı bekleyin. Varsayılan süre 60 saniyedir.
4. Glowroot **Transactions** ekranını açın ve **Web** seçin.
5. Route adlarının ve istek sayılarının gönderdiğiniz trafikle eşleştiğini doğrulayın.

Windows ve Linux native dosyaları temiz `rust-spring v4.6.0` kaynak revision
`0ec9c9df091f225d3e78e6ced4f9b118dd9ba73c` üzerinden üretildi. Linux dosyası GLIBC `2.17` sembol
sınırını korur.
