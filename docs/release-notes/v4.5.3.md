# Rust-Java REST 4.5.3

`4.5.3` is a stable request-path and exporter-scheduling optimization for bounded telemetry.
Existing Java handlers, annotations, services, DTOs, validation, and business logic do not change.

## What Changed

- Enabled telemetry packs the request capture state into one 32-bit field. The native request
  guard is reduced from 32 bytes to at most 24 bytes.
- HTTP sampling still selects exactly one request per configured power-of-two window. The selected
  position rotates with fewer hot-path operations and periodic routes remain covered.
- Exact 5xx accounting and optional bounded slow traces remain unchanged.
- The isolated exporter runs outside the Hyper executor. Linux uses `SCHED_BATCH` with nice value
  `19`; Windows uses `THREAD_PRIORITY_LOWEST`.

## Compatibility

REST ABI remains `29`; Glowroot ABI remains `3`; Dubbo ABI remains `7`; Redis ABI remains `6`. Use
the Windows DLL or Linux SO packaged inside `com.reactor:rust-java-rest:4.5.3`. Do not copy a native
binary into a different Maven version because startup verifies source revision and SHA-256.
