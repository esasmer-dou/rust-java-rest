# Rust-Java REST 4.5.5

[English](v4.5.5.md) | [Turkish](v4.5.5.tr.md)

`4.5.5` is a compatible native-runtime maintenance release. Java handlers, annotations, services,
validation, DTOs, and business logic remain unchanged.

## What Users Get

- A literal IPv4 or IPv6 Glowroot collector address goes directly to the isolated exporter. It no
  longer enters the DNS resolver path.
- The Windows process-thread gauge now reads the real process thread count through the operating
  system API. No Java monitoring thread is added.
- Windows and Linux native files are rebuilt from clean `rust-spring v4.5.5` source revision
  `0498f282556d3f0778a92956b18eaaf96d5c0916` and are protected by packaged SHA-256 provenance.

## Compatibility

REST ABI `29`, Dubbo ABI `7`, Redis ABI `6`, and Glowroot ABI `3` are unchanged. Use the DLL/SO
packaged inside `com.reactor:rust-java-rest:4.5.5`; do not copy native files from another version.

For bounded telemetry, use `java-rust-glowroot-agent:0.4.0`. Telemetry remains disabled unless the
application explicitly enables it.
