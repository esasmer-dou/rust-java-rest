# Rust-Java REST 4.5.5

[English](v4.5.5.md) | [Türkçe](v4.5.5.tr.md)

`4.5.5`, native runtime bakım sürümüdür. Java handler, annotation, service, validation, DTO ve iş
mantığı aynı şekilde çalışır.

## Kullanıcı Ne Kazanır?

- Glowroot collector adresi doğrudan IPv4 veya IPv6 olarak verilirse izole exporter bu adrese
  doğrudan bağlanır. Gereksiz DNS çözümleme yolu çalışmaz.
- Windows process thread ölçümü artık işletim sistemi API'sinden gerçek thread sayısını okur. Bunun
  için Java tarafında ek bir izleme thread'i açılmaz.
- Windows ve Linux native dosyaları temiz `rust-spring v4.5.5` kaynak revision'ı
  `0498f282556d3f0778a92956b18eaaf96d5c0916` üzerinden yeniden üretildi. Paket içindeki SHA-256
  provenance bilgisi dosyaları doğrular.

## Uyumluluk

REST ABI `29`, Dubbo ABI `7`, Redis ABI `6` ve Glowroot ABI `3` değişmedi. Yalnız
`com.reactor:rust-java-rest:4.5.5` paketiyle gelen DLL/SO dosyasını kullanın. Başka sürümden native
dosya kopyalamayın.

Sınırlı telemetri için `java-rust-glowroot-agent:0.4.0` kullanın. Uygulama açıkça etkinleştirmediği
sürece telemetri kapalı kalır.
