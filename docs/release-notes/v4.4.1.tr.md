# Rust-Java REST 4.4.1

`4.4.1`, stable production provenance düzeltmesidir. Java programlama modelini veya HTTP hot path
akışını değiştirmez.

## Neler Değişti?

- Paketlenen Windows ve Linux native dosyaları temiz `rust-spring v4.4.2` CI build'inden gelir.
- Native build bilgisi, kaynak commit'inin 40 karakterli tam SHA değerini bildirir.
- Maven provenance manifesti aynı kaynak revision değerini ve doğrulanmış SHA-256 hash bilgilerini
  taşır.
- Packaged-runtime regresyon testi gerçek native dosyayı yükler ve server başlamadan önce provenance
  sözleşmesinin tamamını doğrular.

## Uyumluluk

| Sözleşme | Değer |
| --- | ---: |
| REST ABI | `28` |
| Dubbo ABI | `7` |
| Redis ABI | `6` |
| Glowroot ABI | `1` |

Java annotation, handler, service, record, validation, route davranışı ve business logic değişmez.
`com.reactor:rust-java-rest:4.4.1` içindeki DLL/SO dosyasını kullanın. Başka bir sürümden native
dosya kopyalamayın.
